# Экспорт паспорта маршрута в Word

Паспорт маршрута регулярного сообщения выгружается из карточки маршрута в
редактируемый файл Microsoft Word (`.docx`). Доступно два оформления:

- **Вариант D** — книжная (портретная) ориентация A4. Ведомственный
  титульный лист с полем «УТВЕРЖДАЮ», страница согласований, схемы и таблицы.
- **Вариант F** — альбомная (ландшафтная) ориентация A4. Технический
  титульный лист со сводной таблицей показателей и широкими таблицами
  остановок.

Оба варианта содержат одни и те же данные маршрута; отличается только
компоновка страниц.

## Как выгрузить

1. Откройте карточку маршрута и нажмите **«Экспорт документов»**.
2. В поле **«Документ»** выберите «Паспорт маршрута Word — вариант D» или
   «… вариант F».
3. Укажите **дату начала действия** (обязательное поле).
4. Нажмите **«Сформировать»** — файл откроется на скачивание с именем вида
   `Паспорт_маршрута_<номер>_<D|F>_<ГГГГ-ММ-ДД>.docx`.

Поле «Сезон» на паспорт не влияет и в документ не попадает — оно используется
только для расписания и ЭРМ.

## Что заполняется автоматически

Из данных маршрута подставляются:

- номер, наименование, начальный и конечный пункты, редакция маршрута;
- перечень остановочных пунктов прямого и обратного направлений;
- расстояния от предыдущей остановки и нарастающим итогом;
- код, адрес и координаты (широта/долгота) остановок;
- длина прямого и обратного направлений (вариант F);
- схема направления и карта OpenStreetMap.

## Редактируемые поля для ручного заполнения

Документ остаётся полностью редактируемым. Пустыми полями («_____») выводятся
реквизиты, которые заполняет исполнитель:

- гриф «УТВЕРЖДАЮ», должность и Ф.И.О. утвердившего, дата утверждения;
- организация-перевозчик;
- согласования с ГИБДД и органом власти;
- характеристики дороги (тип покрытия, ширина, тротуары, сооружения и т. д.);
- дополнительные сведения о дороге.

## Схемы и карты

Для каждого направления формируются два изображения:

1. **Схема направления** — детерминированное схематическое изображение линии
   маршрута с пронумерованными остановками. Строится без обращения к сети.
2. **Карта OpenStreetMap** — растровая карта-подложка с линией маршрута.

Приоритет при построении линии отдаётся сохранённой геометрии маршрута
(ручной или из OSRM). Если геометрия не сохранена, линия строится по
координатам остановок.

Каждая карта содержит указание авторства: **© OpenStreetMap contributors**.

### Работа без доступа к интернету

Если картографические тайлы недоступны (нет сети, превышен тайм-аут 3 секунды),
карта автоматически заменяется схематическим изображением с подписью
«Картографическая подложка недоступна». Файл всегда формируется — сбой сети не
прерывает выгрузку.

## Проверка данных

Если у маршрута нет ни одной остановки, выгрузка отклоняется с сообщением
«Для паспорта маршрута необходимо добавить остановки». Добавьте остановки в
разделах прямого/обратного направления и повторите экспорт. Остановки без
координат отображаются в таблицах, но исключаются из линии на схеме и карте.
