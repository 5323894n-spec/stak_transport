# Красивая Excel-форма наряда на день

Дата: 2026-07-08

## Цель

Существующая кнопка `Excel` в модуле `Наряд на день` должна выгружать не простую таблицу, а аккуратную печатную форму наряда, пригодную для просмотра, печати и оперативной работы диспетчера.

## Выбранный вариант

Реализуется вариант А: текущий endpoint `GET /api/orders/export.xlsx?date=YYYY-MM-DD` остаётся тем же, но содержимое файла становится красивой формой. Дополнительная кнопка или второй лист не добавляются.

## Макет листа

Один лист `Наряд YYYY-MM-DD`.

Верхняя часть:

- строка 1: название предприятия из `settings.org_name`;
- строка 2: крупный заголовок `НАРЯД НА ВЫПУСК АВТОБУСОВ`;
- строка 3: дата, статус наряда, утвердивший пользователь;
- строки 5-7: сводные карточки с итогами.

Сводные показатели:

- всего строк наряда;
- выходов в работе;
- отменённых выходов;
- водителей назначено;
- автобусов назначено;
- часов по плану;
- рейсов по плану;
- пробег по плану;
- топливо по плану.

Основная таблица начинается ниже сводки и содержит текущие поля:

- маршрут;
- выход;
- смена;
- водитель;
- табельный номер;
- автобус;
- госномер;
- явка;
- выезд;
- начало;
- окончание;
- заезд;
- часы;
- рейсов;
- пробег, км;
- плановое топливо, л;
- статус;
- отметки диспетчера.

Поле `отметки диспетчера` добавляется в Excel, потому что оно уже есть в наряде и важно для печатной формы.

Нижняя часть:

- блок подписей: диспетчер, начальник эксплуатации, механик, медработник;
- строка с датой и временем формирования файла.

## Оформление

- альбомная ориентация A4;
- подгонка печати по ширине одной страницы;
- повтор строк заголовка таблицы при печати;
- закрепление области над таблицей;
- скрытые стандартные gridlines;
- заголовок и сводка в сине-серой деловой палитре;
- таблица с фильтрами;
- тонкие светлые границы внутри таблицы и более заметная граница вокруг шапки;
- перенос текста для маршрута, ФИО и отметок;
- числовые колонки выровнены вправо и имеют форматы `0.0` или `0`;
- статус визуально выделяется условным форматированием:
  - `выдан` и `выполнен` — зелёный оттенок;
  - `отменен` — красный оттенок;
  - `план` и `черновик` — нейтральный оттенок;
  - пустой водитель или автобус — предупреждающий жёлтый оттенок.

## Архитектура

Добавить специализированный helper в `app/xl.py`, например `order_xlsx_response(...)`, чтобы не ломать универсальный `xlsx_response(...)`, который используют другие выгрузки.

`app/api_planning.py::order_export` будет собирать данные наряда, настройки предприятия и передавать их в новый helper.

## Проверки

Нужен тест API-выгрузки:

- создаёт временный наряд с одной строкой;
- вызывает `/api/orders/export.xlsx`;
- открывает файл через `openpyxl.load_workbook`;
- проверяет заголовок `НАРЯД НА ВЫПУСК АВТОБУСОВ`;
- проверяет наличие колонки `Отметки`;
- проверяет `freeze_panes`, `auto_filter`, альбомную ориентацию и наличие блока подписей;
- проверяет, что в таблицу попали водитель, автобус и статус.

## Не входит в задачу

- создание отдельного PDF;
- изменение HTML-печатной формы наряда;
- добавление новых пользовательских кнопок;
- изменение логики формирования наряда;
- импорт обратно из Excel.
