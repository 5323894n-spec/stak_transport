# Редактируемый Excel-график водителей

## Решение

Реализуется вариант C: комбинированная Excel-книга для модуля "График водителей".

Книга должна быть красивой для печати и удобной для ручного редактирования в Excel. Она не заменяет табель и не меняет текущую выгрузку в 1С. Для графика добавляется отдельная выгрузка `GET /api/roster/export.xlsx?month=YYYY-MM`.

## Цели

- Показать месячный график водителей в привычном виде: водители по строкам, дни месяца по колонкам.
- Отображать рабочее время с подготовительно-заключительным временем.
- Показывать маршрут, выход, смену, диапазон рейсов, начало, окончание, обед/перерыв и итог часов.
- Дать возможность редактировать файл в Excel: редактируемые поля подсвечены, формулы остаются пересчитываемыми.
- Выводить предупреждения по режиму труда и отдыха как справочную информацию, без блокировки выгрузки.

## Не входит в первый этап

- Обратная загрузка Excel-файла в систему.
- Макросы, VBA и внешние подключения.
- Автоматическое изменение графика в базе после ручного редактирования Excel.

Это ограничение важно: пользователь может править Excel как рабочий документ, но база не перезаписывается случайно.

## Структура Excel-книги

### Лист 1: "График месяца"

Печатная форма для руководителя, диспетчера и эксплуатации.

Верхняя часть:

- название организации;
- заголовок "ГРАФИК РАБОТЫ ВОДИТЕЛЕЙ";
- месяц;
- дата формирования;
- краткие итоги: рабочих смен, рабочих часов, ПЗВ, ночных часов, предупреждений.

Основная таблица:

- табельный номер;
- ФИО водителя;
- колонки дней месяца;
- итоги справа: рабочих дней, линия, ПЗВ, перерывы, всего часов, ночные, предупреждения.

Ячейка дня для работы показывает:

- маршрут;
- выход/смену;
- начало и окончание;
- ПЗВ;
- итог часов;
- для двух назначений в один день - несколько строк внутри одной ячейки.

Цвета:

- работа - светло-синий;
- выходной - серый;
- резерв - желтый;
- отсутствие - светло-красный;
- предупреждение - желтый акцент;
- формулы итогов - светло-зеленый.

### Лист 2: "Назначения"

Редактируемая таблица. Одна строка соответствует одному назначению водителя на дату.

Колонки:

- дата;
- табельный номер;
- водитель;
- статус дня;
- маршрут;
- выход;
- смена;
- рейсы с/по;
- начало работы;
- окончание работы;
- ПЗВ, мин;
- обед/перерыв, мин;
- линейное время, ч;
- рабочее время с ПЗВ, ч;
- ночные часы;
- комментарий.

Редактируемые колонки подсвечиваются светло-желтым:

- статус дня;
- маршрут;
- выход;
- смена;
- рейсы с/по;
- начало;
- окончание;
- ПЗВ;
- обед/перерыв;
- комментарий.

Расчетные колонки остаются формулами:

- линейное время;
- рабочее время с ПЗВ;
- ночные часы;
- итоговые суммы.

### Лист 3: "Проверки 424"

Справочный лист предупреждений. Источник - действующий движок проверок `norms.check_period`.

Колонки:

- дата;
- водитель;
- тип предупреждения;
- важность;
- факт;
- норма;
- рекомендация.

Нарушения не блокируют экспорт и не блокируют ручную работу с файлом.

### Лист 4: "Справочники"

Служебный лист для читаемости и ручного редактирования:

- маршруты;
- водители;
- статусы дня;
- активные нормы: ПЗВ, медосмотр, недельная норма.

## Источники данных

Используются существующие таблицы:

- `drivers`;
- `routes`;
- `roster`;
- `roster_assignments`;
- `norms`;
- `calendar`.

Если у водителя есть записи в `roster_assignments`, они считаются основным источником детального графика. Если назначений нет, используется агрегированная строка `roster`.

ПЗВ по умолчанию берется из активных норм `prep_final_minutes`. В Excel ПЗВ выводится отдельной редактируемой колонкой. Итоговое рабочее время в листе "Назначения" пересчитывается формулой от начала, окончания, ПЗВ и перерыва.

## Изменения в интерфейсе

В модуле "График водителей" добавляется отдельная кнопка:

- "График в Excel".

Существующий экспорт табеля не удаляется. Чтобы не путать действия, текущая кнопка может быть подписана как "Табель в Excel".

## Архитектура

Добавить helper в `app/xl.py`:

- `roster_xlsx_response(month, settings, drivers, roster_rows, assignments, warnings, routes, norms, filename)`.

Добавить endpoint в `app/api_planning.py`:

- `GET /api/roster/export.xlsx?month=YYYY-MM&division=`.

Endpoint:

1. Проверяет формат месяца.
2. Вычисляет начало и конец месяца.
3. Загружает водителей, график, назначения, маршруты и активные нормы.
4. Получает предупреждения через `norms.check_period`.
5. Возвращает workbook через `roster_xlsx_response`.

## Ошибки и пустые данные

- При неверном формате месяца возвращается `400`.
- Если график пустой, файл все равно формируется: водители остаются в списке, дни пустые или выходные.
- Предупреждения 424 попадают на лист "Проверки 424", но не блокируют выгрузку.

## Тестирование

Добавить тест `tests/test_roster_excel_export.py`.

Проверить:

- endpoint возвращает `.xlsx`;
- в книге есть листы "График месяца", "Назначения", "Проверки 424", "Справочники";
- заголовок содержит месяц;
- строка назначения содержит начало, окончание и ПЗВ;
- расчетные ячейки на листе "Назначения" являются формулами;
- редактируемые ячейки имеют выделяющую заливку;
- предупреждения 424 попадают на отдельный лист;
- кнопка в `static/app.js` ведет на `/api/roster/export.xlsx`.

## Критерии готовности

- В модуле графика есть понятная кнопка Excel-графика.
- Файл открывается в Excel без макросов и защиты.
- Пользователь видит время работы с ПЗВ.
- Пользователь может вручную редактировать ключевые поля.
- Формулы пересчитывают итоги в файле.
- Полный набор тестов проходит.
