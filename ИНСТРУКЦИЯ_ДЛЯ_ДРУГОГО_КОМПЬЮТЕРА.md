# Инструкция по запуску ATP Servis V2 на другом компьютере

Эта инструкция нужна, чтобы перенести и запустить программу ATP Servis V2 на другом компьютере Windows.

## 1. Что нужно скопировать

Скопируйте целиком папку программы:

```text
atp-system
```

Внутри должны быть основные файлы и папки:

```text
app
static
requirements.txt
run.py
start.bat
atp.db
```

Важно: файл `atp.db` содержит рабочую базу данных программы. Если нужна текущая база с маршрутами, графиками, нарядами и путевыми листами, копируйте его вместе с программой.

## 2. Что установить на новом компьютере

На новом компьютере установите Python 3.11 или новее.

Скачать Python можно с официального сайта:

```text
https://www.python.org/downloads/windows/
```

При установке обязательно поставьте галочку:

```text
Add Python to PATH
```

## 3. Установка зависимостей

Откройте папку `atp-system`.

В адресной строке проводника напишите:

```text
cmd
```

и нажмите Enter.

В открывшемся окне выполните команду:

```bat
python -m pip install -r requirements.txt
```

Если команда `python` не работает, попробуйте:

```bat
py -m pip install -r requirements.txt
```

## 4. Запуск программы

После установки зависимостей запускайте программу двойным кликом по файлу:

```text
start.bat
```

Файл находится в корне папки `atp-system`.

При запуске откроется адрес:

```text
http://127.0.0.1:8001/
```

Окно запуска закрывать нельзя, пока работает программа.

## 5. Если программа уже запущена

Если сервер уже работает, повторный запуск `start.bat` просто откроет программу в браузере.

## 6. Если порт 8001 занят

Если программа не запускается и написано, что порт занят, можно временно запустить вручную на другом порту:

```bat
python run.py --port 8002
```

После этого откройте в браузере:

```text
http://127.0.0.1:8002/
```

## 7. Резервная копия базы

Перед переносом или обновлением рекомендуется сделать копию файла:

```text
atp.db
```

Например:

```text
atp_backup_2026-07-10.db
```

## 8. Быстрая проверка

После запуска проверьте в меню программы:

- Расписание
- График водителей
- Сводное расписание
- Наряд
- Путевые листы

Если эти разделы открываются, программа перенесена правильно.

## 9. Куда обращаться при ошибке

Если программа не запускается, проверьте:

1. Установлен ли Python.
2. Выполнена ли команда `pip install -r requirements.txt`.
3. Есть ли файл `atp.db` в папке программы.
4. Не занят ли порт `8001` другой программой.
5. Не закрыто ли окно сервера после запуска `start.bat`.
