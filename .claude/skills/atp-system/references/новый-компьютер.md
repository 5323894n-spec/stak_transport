# Перенос работы на другой компьютер

Пошагово, для Windows. Всё, что нужно поставить один раз, и чек-лист проверки.

## 1. Перед уходом со старого компьютера

```bash
cd C:\atp-system-local
python -m pytest -q          # тесты должны быть зелёными
git status                   # посмотреть, что не закоммичено
git add -A && git commit -m "wip: ..."
git push github main         # или свою ветку: git push github codex/<имя>
```

Важно: база `atp.db` в git **не** попадает. Если нужны именно текущие рабочие
данные (маршруты, графики, наряды), скопируйте файл `atp.db` вручную —
флешкой, Google Диском или командой из `копирование на google.txt`.
Для разработки это не обязательно: на новом компьютере база создастся заново,
а `--demo` наполнит её тестовым АТП.

## 2. Что установить на новом компьютере

| Программа | Зачем | Проверка |
|---|---|---|
| Python 3.10+ (галочка «Add Python to PATH») | сервер и тесты | `python --version` |
| Git | получение кода | `git --version` |
| Node.js LTS | часть тестов интерфейса | `node --version` |
| Claude Code | продолжение доработки | `claude --version` |

## 3. Получить проект

```bash
git clone https://github.com/5323894n-spec/stak_transport.git
cd stak_transport
python -m pip install -r requirements.txt
```

Скилл `atp-system` лежит внутри репозитория (`.claude/skills/atp-system/`),
поэтому после клонирования Claude Code подхватит его автоматически — отдельно
переносить ничего не нужно.

## 4. Проверить, что всё работает

```bash
python run.py --demo
```

Открыть http://127.0.0.1:8000, войти `admin` / `admin` и проверить разделы:
Расписание, График водителей, Сводное расписание, Наряд, Путевые листы,
Ремонт и ТО, Диспетчер, Выручка. Затем остановить сервер (Ctrl+C) и прогнать
тесты:

```bash
python -m pytest -q
```

Всё зелёное — среда готова, можно продолжать доработку.

## 5. Ежедневный запуск для пользователя

- `update.bat` — обновить код с GitHub и запустить (порт 8001);
- `start.bat` — просто запустить (порт 8001);
- в PowerShell запускать с префиксом: `.\update.bat`.

Если порт занят: `python run.py --port 8002`.

## 6. Возврат работы обратно

```bash
python -m pytest -q && git push github <ветка>
```

На старом компьютере потом: `git pull` (в папке `C:\atp-system-local`
основной remote для GitHub называется `github`, поэтому `git pull github main`).

## 7. Частые проблемы

| Симптом | Причина и решение |
|---|---|
| `python` не найдена | Python не в PATH — переустановить с галочкой «Add Python to PATH» или использовать `py` |
| `ModuleNotFoundError: fastapi` | не выполнен `python -m pip install -r requirements.txt` |
| Тесты падают с «Node.js is required» | не установлен Node.js — код тут ни при чём |
| Порт 8001 занят | программа уже запущена в другом окне, либо `python run.py --port 8002` |
| В браузере старый интерфейс | не поднята версия `?v=` у скрипта в `static/index.html`; временно — Ctrl+F5 |
| `git pull` не проходит fast-forward | есть локальные незакоммиченные правки — закоммитить или отложить (`git stash`) |
| Пропали данные | база `atp.db` на каждом компьютере своя; восстановить из копии |
